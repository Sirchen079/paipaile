## 二、硬性规格

- **透明背景**（PNG，alpha 通道）。底衬图同样透明底。绝不要白底/纯色底。
- **分辨率**：字图宽 ≥ 2048px；5 字招（超级冲击波、究极冲击波）建议 2560px 宽。底衬带宽 ≥ 2560px。
- **构图**：横排一行，字占画面高度 70% 以上，四周留白 ≤ 8%。字可微有大小错落、整体允许 ≤ 5° 的斜势（游戏内会再压 -2.5° 旋转）。
- **风格基调**：国风水墨 · 榜书/擘窠大字，厚重有力，笔画带飞白；边缘允许少量墨点溅洒，但不要飞溅到画面边缘。
- **一致性**：6 张必须同一套笔法、同一套墨色体系（建议一次会话同 prompt 批量出，只换文字和主色）。

## 三、配色体系（重要）

游戏是米白宣纸底 + 焦墨 + 朱砂的水墨 UI。美术字用「墨骨色填」结构：

- **笔画主体**：焦墨/浓墨（近黑 `#1c1712`），保证在米白战场底色上压得住；
- **主色只作点缀**：朱砂描边、起承转合处的色晕、或个别笔画挑色（如金字可整字金墨）。**不要整字纯色平填**——纯紫/纯蓝平填会立刻出戏成卡通；
- 允许极少量金粉/火星质感的高光（锤天锤地、究极冲击波适用）。

## 四、逐招气质提示

- **超级冲击波**：紫电缠绕笔锋，锋芒外露，气势外放。
- **锤天锤地**：最厚重的一张，笔画如斧劈锤砸，可带火色余烬。
- **一阳指**：金字，笔画收束成一道锐利的「指」势，挺拔凝聚，忌肥。
- **魔爆术**：暗紫，笔画扭曲躁动、墨意癫狂，可有轻微炸墨。
- **扭曲虚空**：蓝墨，笔画带漩涡/塌陷动势，冷、深、虚。
- **究极冲击波**：全书道排面之最——字最大、墨最浓、朱红描边最烈，可加一道贯穿字后的飞白长锋。

## 五、反面要求（negative）

- 不要背景、不要边框/卷轴/牌匾、不要拼音或英文、不要印章外的任何装饰图案
- 不要卡通描边/动漫高光/3D 立体字/金属渐变字
- 不要竖排、不要多行
- 不要错字——生成后逐字核对（AI 生图中文字极易错字，错字即废片）

## 六、参考 prompt 模板（中英文各一，按需取用）

中文：
> 中国风水墨书法榜书大字「锤天锤地」，横排一行，焦墨浓笔，笔画厚重如斧劈，带飞白，朱砂红描边点缀，微量火星金粉高光，透明背景，纯文字无其他元素，字占画面高度70%以上

English：
> Chinese ink calligraphy, large bold bafen/榜书 characters "锤天锤地", single horizontal row, heavy jet-black dry brush strokes with feibai (flying white) texture, subtle vermillion red edge accents, faint ember-gold highlights, isolated on transparent background, no background, no border, no frame, characters fill 70% of image height

## 七、接入约定（给开发的备注）

- 投放路径：`web/public/titles/`，文件名按上表。
- 游戏内以「图等比缩到 2V≈64px 字高 / 3V≈140px 字高」显示，动画沿用现有逐字砸入节奏改为整图一次砸入 + 墨带扫入。
- 若只交了 6 张字图未交底衬，底衬继续用现有 SVG 墨带重绘版。
